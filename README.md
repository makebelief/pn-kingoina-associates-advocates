# P. N. King’oina & Associates Advocates — Website Demo

Responsive multi-page static website prepared from the supplied firm logo, portraits, flyer and professional profile.

## Included
- Home
- About
- Practice Areas + six dedicated practice pages
- Paul Nyakundi King’oina profile
- Insights
- Contact
- Privacy
- Legal notice
- 404 page
- Responsive navigation + floating contact rail
- SEO metadata, LegalService structured data, sitemap and robots.txt
- Vercel configuration

## Local check
```bash
npm run check
```

## Deployment
This is a static project and can be deployed directly to Vercel. Replace the sitemap host with the final production domain after the domain is confirmed.
